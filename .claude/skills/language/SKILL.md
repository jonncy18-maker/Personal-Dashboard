## Language

**Language splits into two different shapes — French (hours) vs Spanish (ambient), and neither should be forced into the other's mold.** French is the active learning project: `/api/french-progress` + `lib/french-progress.js` (Haiku, vision) read whatever's legible off a screenshot John uploads of Dreaming French's progress page — no public API exists for Dreaming French/Dreaming Spanish (checked; third-party tools only ride a logged-in browser session, not a stable server-to-server credential, so there's no fit here). The screenshot import is the app's fourth distinct AI use — same **never-auto-save** discipline as Travel's itinerary import: John reviews/edits the preview (`ProgressPreview` in `app/language/page.jsx`) and only `/api/french-progress/save` ever writes to `french_hours_daily` (a dated log, upserted by date so a re-imported overlapping screenshot just corrects those days) and `french_hours_summary` (the singleton headline total — kept separate from summing the daily log, since a screenshot rarely shows full history and summing would understate real progress). Spanish, by contrast, is already C1 and on the way to C2 — it's ambient/daily (phone, podcasts, music, tutor calls), not something with an hours metric to log; forcing a fake "last active" or hours count onto it would either be meaningless or busywork. It gets `language_notes` instead: one freeform, John-edited line (no AI, no derived stat) plus the existing live tutor-call countdown from Calendar. Migration 011.
