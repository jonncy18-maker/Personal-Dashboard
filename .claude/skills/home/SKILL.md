## Home

**Home's hero photo changes with the time of day — cached, never per-load, and honest.** The Home hero shows a scenic Unsplash photo matching the viewer's local time band (Dawn 5–8 / Day 8–17 / Golden 17–20 / Night 20–5 — `lib/time-of-day.js`). The client picks the band from its own clock and calls `/api/hero-image?band=…`, which caches one photo per band per calendar day in `hero_image` — so a page load never hits Unsplash unless that band hasn't been fetched yet today (same discipline as the trip photo). No key / no result falls back to a per-band CSS gradient — never a broken image. The greeting uses `timeOfDayGreeting`; the quote is a generic, **unattributed** line from `lib/quotes.js` rotating once a day (John's call — no personal byline). **A band can play a looping video instead of the photo.** `BAND_VIDEO` in `lib/time-of-day.js` lists the bands with a clip (Google Flow, generated by John; 1600 px, no audio, MP4 + WebM + a JPEG poster in `public/hero/`). All four bands have one as of 2026-09-25. How each loops depends on the take: a clip that barely changes over its length gets a 1 s crossfade seam (Day); one that changes a lot ping-pongs, forward then reversed (Dawn, Golden, Night), because a crossfade there shows as a dissolve. Each clip carries a `focus` (vertical `object-position`) because the wide desktop hero keeps only a middle band of a 16:9 frame; set it from where that take's horizon sits. A video band skips `/api/hero-image`; a band removed from `BAND_VIDEO` falls back to the Unsplash photo. Reduced motion or Data Saver always gets the poster, never the video, and the hero always carries a pause button when the video plays (WCAG 2.2.2) — don't remove either. Keep clip files small (a few MB); a new clip is a new entry in `BAND_VIDEO` plus its three files, nothing else. Do **not** add fabricated Home metrics (a "daily focus %", per-card progress rings, weather) — they have no data source, the same reason the Language "weekly goal" ring was deleted; a Home stat must come from real data or not appear.

**Card pills are state, never captions — and empty cards go quiet.** Every Home card's pill is derived from its data (Car's "On pace" is the model: "In 37 days", "Not started"/"On track"/"Over", "Clear"); a card with no state to report passes no pill rather than a fixed word like "Active" or "Review". A card with nothing in it (0 open schedules, 0 ideas, 0 starred emails) renders `quiet` — sunken, dashed, untinted — and lights back up the moment there's data. Cards are grouped **Today** (Health, Schedules, Language, Email) and **Horizon** (Travel, Car, AI Projects, Ideas), four each, to fill the 4-column grid; a new domain card means rebalancing the groups, not leaving an orphan. Meters on cards show only real ratios (Car's Year-1 projection vs allowance, Health's eaten vs target) — never a goal Home made up.
